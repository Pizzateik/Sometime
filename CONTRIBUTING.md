# Contributing

Bug reports, feature requests, and focused pull requests are welcome.

## Set up the project

1. Install Flutter 3.47.2 with a compatible Dart 3.13 SDK.
2. Clone the repository.
3. Run `flutter pub get`.
4. Run `flutter run` on an Android device or emulator.

## Check a change

Run these commands before you open a pull request:

```bash
flutter analyze
flutter test
```

Keep each change focused. Explain the reason for the change and add tests when behavior changes.

Open an issue before a large change so contributors can discuss its fit with Sometime.
