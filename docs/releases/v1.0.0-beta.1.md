# Sometime 1.0 Beta 1

This is the first Android beta for Sometime. Use it for testing before the stable 1.0 release.

## Included

- Today, Soon, and Sometime task horizons.
- Spaces, reminders, recurring tasks, and natural date recognition.
- Android pinned task notifications and home screen widgets.
- Local import and export.
- Light, dark, soft, Material You, and custom color options.
- English, German, Spanish, Portuguese, French, and Japanese text.

## Privacy

Sometime needs no account. It has no analytics, advertising, task telemetry, or cloud backend of its own.

## Install

Download the attached APK and install it on Android 7.0 or later. Android can ask for permission to install an app from your browser or file manager.
